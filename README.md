# AR MART — Part 1 (Vertical Slice)

See the response body for full setup commands.

Quick start:
1. `cp .env.example .env` and set `MONGODB_URI`.
2. `npm install`
3. `npm run seed`
4. `npm run dev:api`  (terminal 1)
5. `npm run dev:web`  (terminal 2)
6. Open http://localhost:3000

Part 1 delivers: storefront, ground-floor 3D grocery mart, shared cart,
demo checkout, order persistence in MongoDB.
Parts 2-6 are outlined at the bottom of the accompanying answer.
